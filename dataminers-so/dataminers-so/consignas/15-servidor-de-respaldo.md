# Servidor de respaldo

**Etiqueta:** Administración de SO

## Consigna

Configurar un servidor destinado al almacenamiento y gestión de las copias de seguridad del sistema.

## Archivos que la resuelven

- `scripts/servidor_respaldo.sh`

## Cómo probarla

```bash
sudo ./scripts/servidor_respaldo.sh ayuda
sudo ./scripts/servidor_respaldo.sh instalar
sudo ./scripts/servidor_respaldo.sh estado
```
