# Probar restauración de backup

**Etiqueta:** Administración de SO

## Consigna

Realizar una restauración de prueba para comprobar que los backups pueden recuperarse correctamente y que los datos mantienen su integridad.

## Archivos que la resuelven

- `scripts/probar_restauracion.sh`

## Cómo probarla

```bash
sudo ./scripts/probar_restauracion.sh ayuda
sudo ./scripts/probar_restauracion.sh todo
```
