# Script de base de datos

**Etiqueta:** Administración de SO

## Consigna

Crear un script para automatizar la configuración, creación y preparación de la base de datos del sistema.

## Archivos que la resuelven

- `scripts/basedatos.sh`
- `docker/initdb/01_schema.sql`

## Cómo probarla

```bash
sudo ./scripts/basedatos.sh ayuda
sudo ./scripts/basedatos.sh preparar
sudo ./scripts/basedatos.sh estado
```
