# Script de logs

**Etiqueta:** Administración de SO

## Consigna

Automatizar la configuración y gestión de registros del sistema para facilitar el monitoreo y detección de errores.

## Archivos que la resuelven

- `scripts/logs.sh`

## Cómo probarla

```bash
sudo ./scripts/logs.sh ayuda
sudo ./scripts/logs.sh configurar
sudo ./scripts/logs.sh resumen
```
