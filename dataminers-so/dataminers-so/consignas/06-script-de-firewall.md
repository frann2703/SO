# Script de firewall

**Etiqueta:** Administración de SO

## Consigna

Configurar mediante scripts las reglas de firewall necesarias para permitir únicamente las conexiones requeridas.

## Archivos que la resuelven

- `scripts/firewall.sh`

## Cómo probarla

```bash
sudo ./scripts/firewall.sh ayuda
sudo DRY_RUN=1 ./scripts/firewall.sh aplicar
```
