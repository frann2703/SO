# Script de backups

**Etiqueta:** Administración de SO

## Consigna

Crear un script que permita realizar copias de seguridad de forma automatizada y organizada.

## Archivos que la resuelven

- `scripts/backups.sh`

## Cómo probarla

```bash
sudo ./scripts/backups.sh ayuda
sudo ./scripts/backups.sh archivos
sudo ./scripts/backups.sh listar
```
