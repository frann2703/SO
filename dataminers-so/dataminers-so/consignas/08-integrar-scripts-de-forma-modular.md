# Integrar scripts de forma modular

**Etiqueta:** Administración de SO

## Consigna

Organizar los diferentes scripts en módulos independientes y crear una estructura que permita ejecutarlos y administrarlos de forma centralizada.

## Archivos que la resuelven

- `scripts/administrar.sh`

## Cómo probarla

```bash
sudo ./scripts/administrar.sh modulos
sudo ./scripts/administrar.sh estado
sudo ./scripts/administrar.sh menu
```
