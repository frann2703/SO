# Script de grupos

**Etiqueta:** Administración de SO

## Consigna

Automatizar la creación y administración de grupos y la asignación de usuarios y permisos correspondientes.

## Archivos que la resuelven

- `scripts/grupos.sh`

## Cómo probarla

```bash
sudo ./scripts/grupos.sh ayuda
sudo ./scripts/grupos.sh base
sudo ./scripts/grupos.sh listar
```
