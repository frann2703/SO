# Script de usuarios

**Etiqueta:** Administración de SO

## Consigna

Crear scripts para automatizar la gestión de usuarios del sistema, incluyendo altas, bajas, modificaciones y configuraciones necesarias.

## Archivos que la resuelven

- `scripts/usuarios.sh`

## Cómo probarla

```bash
sudo ./scripts/usuarios.sh ayuda
sudo ./scripts/usuarios.sh crear mperez "Maria Perez" dm_dev
sudo ./scripts/usuarios.sh info mperez
```
